## 安全事件与处理
- `scripts/setup_secrets.py` 曾硬编码 GitHub PAT（ghp_...），被 GitHub push protection 拦截
- 已改为从环境变量 `GITHUB_TOKEN` 读取，并用 `git filter-branch` 清除历史中的 token，force push 覆盖
- Docker Hub token（dckr_pat_...）仅存在于 shell 命令与对话中，未进仓库
